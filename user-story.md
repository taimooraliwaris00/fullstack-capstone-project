## User Stories

### User Story 1 — User Registration

**As a** new user
**I want** to register for an account
**So that** I can access GiftLink and participate in sharing household items.

### User Story 2 — User Login

**As a** registered user
**I want** to log in securely
**So that** I can access my profile and manage my activities.

### User Story 3 — List an Item

**As a** user
**I want** to list household items that I no longer need
**So that** other users can reuse or recycle them.

### User Story 4 — Search Items

**As a** user
**I want** to search for items by keyword or category
**So that** I can quickly find items that I need.

### User Story 5 — View Item Details

**As a** user
**I want** to view detailed information about an item
**So that** I can decide whether the item is suitable for me.

### User Story 6 — Comment on Items

**As a** user
**I want** to comment on an item listing
**So that** I can ask questions or communicate feedback about the item.

### User Story 7 — Edit Profile

**As a** registered user
**I want** to edit my profile information
**So that** I can keep my account details up to date.

### User Story 8 — Manage Listings

**As a** user
**I want** to update or remove my item listings
**So that** I can keep my posted items accurate and current.

### User Story 9 — Secure Authentication

**As a** user
**I want** my account to use secure authentication
**So that** my personal information and account activities are protected.

### User Story 10 — Reuse Household Items

**As** an environmentally conscious user
**I want** to find free household items from other users
**So that** I can reuse items instead of purchasing new ones.
